# 零担配载核价台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

零担报价的配载核价台：每笔报价选车型（小货车 / 厢式车）、填线路、运费和托盘货；托盘货逐项记托盘数、每托重量和是否可叠放。

## 核价规则

- 小货车限 1800 公斤 / 8 个托位，厢式车限 3500 公斤 / 12 个托位
- 可叠放货物两托占一位（向上取整），不可叠放一托占一位
- 超重或缺位的报价标记「待调整」，并写清超出几公斤或几位
- 核价通过为「可配载」，确认后「已确认」并占用车辆托位与载重

## 版本与占位

- 改货另建版本，旧报价保留在版本历史里
- 已确认的报价改货时先退旧占位，再按新货重新核价
- 车辆占位看板实时汇总已确认报价占用的托位与重量

## 目录结构（资料、核价、保存、页面分开）

- `src/domain/` 资料：类型、车型限值、示例数据
- `src/pricing/` 核价：配载计算纯函数（总重、托位、超限）
- `src/storage/` 保存：localStorage 读写
- `src/stores/` 状态编排（Pinia）
- `src/pages/` 页面：报价表单、报价卡片、车辆占位看板

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
